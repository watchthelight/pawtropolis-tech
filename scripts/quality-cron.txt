# Crontab line of the chat research job on the production host.
#
# The job (scripts/research.ts, built to dist/scripts/research.js) scores the
# messages of the main chat and writes data/research.db, the file the
# dashboard's Quality tab reads. A run looks at the last three days; the first
# run after 09:00 UTC of a day goes over the whole channel. A run scores at
# most 2000 messages and leaves the rest to the next one.
#
# flock: a run is skipped while the one before it is still at work.
# nice:  the bot shares the host's two CPUs with the job and goes first.
#
# Log: data/research.log gets one line of JSON per run, with counts and times
# and never the text of a message.
#
# Install once on the host. This puts the line into the crontab that is there
# and replaces an earlier version of it:
#   ssh bash-ec2 'cd /home/ubuntu/pawtropolis-tech && (crontab -l 2>/dev/null | grep -v "dist/scripts/research.js"; grep -v "^#" scripts/quality-cron.txt | grep .) | crontab -'
#
# The deploy installs the job's library (research/) and fetches its model files
# (data/research-model). The study this job grew out of had its scripts started
# from the crontab too. Those lines did no work after 2026-05-15, when the
# study's tables were dropped on the host, and were removed on 2026-11-15
# (#00295).

*/15 * * * * cd /home/ubuntu/pawtropolis-tech && flock -n data/research.lock nice -n 10 /usr/bin/node dist/scripts/research.js >> data/research.log 2>&1
