# Crontab entries for the EC2 chat-quality worker pipeline.
#
# Install once on EC2:
#   ssh bash-ec2 'crontab -l 2>/dev/null > /tmp/crontab.bak; \
#                 cat /home/ubuntu/pawtropolis-tech/scripts/quality-cron.txt >> /tmp/crontab.bak; \
#                 sort -u /tmp/crontab.bak | crontab -'
#
# Each script is resumable / capped; everything here is sub-50MB.
#
# The embedding step (embed-incremental.mjs) was removed with #00089: it imported
# @xenova/transformers, which #00003 deleted for a protobufjs RCE, so the job could
# never run under `npm ci --omit=dev` and fetched unpinned remote model weights.
#
# Logs: /tmp/quality-*.log (rotate yourself if they grow large; not critical).

*/15 * * * * cd /home/ubuntu/pawtropolis-tech && /usr/bin/node scripts/build-context-incremental.mjs >> /tmp/quality-ctx.log 2>&1
