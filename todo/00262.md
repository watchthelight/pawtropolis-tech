# #00262 -- Claim all open button on the reviews page

**Type:** feat | **Priority:** Low

The bot developer clearing a review backlog has to open each application and claim it one at a time. A single button on the queue that claims everything unclaimed removes that grind.

**Location:** `web/src/routes/dashboard/reviews/+layout.svelte` (filter bar), reusing `POST /api/review/claim`

**Approach:** the button loops the unclaimed application IDs through the existing per-application claim endpoint rather than adding a bulk route. That reuses the permission gate in `web/src/lib/server/reviewGate.ts`, the UUID validation, and the 409 already-claimed handling without duplicating any of it. Requests go one at a time so a long queue cannot hammer the bot API.

**Behavior:**

- Visible only at owner tier, matching the bypass in `canPerformReviewAction`.
- Confirm step showing the count, because claiming twenty applications by accident is tedious to undo.
- Progress while running, then a result line reporting claimed, already taken, and failed.
- Refreshes the queue and tab counts when it finishes.
- Disabled when nothing is unclaimed.

**Status:** implemented and deployed on 2026-08-29 in the same pass that filed this. Recorded here so the backlog reflects the request.
