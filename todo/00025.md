# #00025 -- Add setDMPermission(false) to guild-only commands

**Type:** chore | **Priority:** Low

Multiple guild-only commands lack `.setDMPermission(false)` on their SlashCommandBuilder. Discord still shows them in DMs; users get confusing runtime denial messages instead of having the command hidden.

2. Add `.setDMPermission(false)` to their builders.
3. Run npm run deploy:cmds on a dev guild to verify.
