# #00273 -- Dashboard config editor is missing 17 bot-editable columns

**Type:** feat | **Priority:** Medium | **Status:** `WIP`

The bot accepts these `guild_config` columns through `upsertConfig` (`src/lib/config.ts` allowlist) but the dashboard editor has no field metadata or update rule for them, so `/api/config/update` rejects them with 400 and they can only be changed from Discord: `avatar_scan_hard_threshold`, `avatar_scan_nsfw_threshold`, `avatar_scan_racy_threshold`, `avatar_scan_skin_edge_threshold`, `avatar_scan_soft_threshold`, `backfill_notification_channel_id`, `banner_sync_interval_minutes`, `circuit_breaker_threshold`, `level_reward_dm_enabled`, `poke_excluded_channel_ids_json`, `pulse_excluded_category_ids_json`, `qotd_review_channel_id`, `qotd_role_id`, `server_artist_channel_id`, `unverified_rules_channel_id`, `verify_thread_parent_id`, `vote_out_threshold`.

**Fix:** add `FIELD_META` entries with the right widget types in `web/src/lib/server/queries/config.ts` and matching `CONFIG_FIELD_RULES` in `web/src/routes/api/config/update/+server.ts`; `panic_mode` stays display-only with a note. The parity test in #00272 locks the two sets together.

## Update 2026-09-01 (done, pending deploy)

Real gap was 7 columns without field metadata and 4 without a validation rule (the other 10 of the original 17 already had metadata). Added `qotd_review_channel_id`, `verify_thread_parent_id`, `unverified_rules_channel_id`, `qotd_role_id`, `level_reward_dm_enabled`, `pulse_excluded_category_ids_json`, `vote_out_threshold` to FIELD_META, and rules for `pulse_excluded_category_ids_json` (json), `vote_out_threshold` (1 to 10), `verify_thread_parent_id` and `unverified_rules_channel_id` (channels) to both `src/lib/configValidation.ts` and the dashboard copy. `ALLOWED_CONFIG_COLUMNS` is exported and `tests/docs/config-editor.test.ts` holds the four sets together. Ships with 6.2.1.
