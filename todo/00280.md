# #00280 -- v26 security fixes: forged dashboard sessions, GitHub token leak, dashboard API exposure

**Type:** security | **Priority:** Critical | **Status:** `WIP`

From the v26 audit (`MODERNIZATION_PLAN.md` section 3).

- SEC-1: `web/src/lib/server/session.ts` accepts a plain JSON cookie when decryption fails, so a session can be forged.
- SEC-2: a failed `git push` in `/update banner`, `/update avatar` and the server audit docs job puts the GitHub bot token into a public reply and the logs.
- SEC-3: the internal dashboard API listens on all interfaces and compares its secret with `!==`.
- SEC-8: workflows have no `permissions:` block and one third-party action is pinned by tag.
