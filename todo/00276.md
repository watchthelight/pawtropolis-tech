# #00276 -- Backfill process stuck in waiting restart

**Type:** bug | **Priority:** Medium | **Status:** `WIP`

`pm2 describe pawtropolis-backfill` on the host shows `waiting restart`, 1 restart, uptime 0, error log `~/.pm2/logs/pawtropolis-backfill-error-6.log`. The archive already holds 3.1M messages (`messages_archive` max rowid 3,125,749), so the run may simply be finished, or it crashed mid-run. `ecosystem.config.cjs` lists it with `autorestart: false`, and every `pm2 startOrRestart` on deploy starts it again.

**Decision (plan D14):** read the error log; if the run finished or crashed after completing, remove the app from `ecosystem.config.cjs` and `pm2 delete` it, keeping `scripts/backfill/run.ts` as a manual tool documented in `scripts/README.md`. If it crashed mid-run, fix the crash, cap its write batches at 500 rows with a yield between batches (#00270), and let it finish.
