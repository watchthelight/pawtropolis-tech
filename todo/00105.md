# #00105 -- Finalize button interaction is awaited but never acknowledged → user sees 'This interaction failed'

**Type:** bug | **Priority:** Medium

The Finalize button press is captured via `await uploadMessage.awaitMessageComponent(...)` (line 179) but the resolved component interaction is discarded - it is never acknowledged with update()/deferUpdate()/reply(). Discord requires every component interaction to be acknowledged within 3 seconds; otherwise the client shows a red 'This interaction failed' on the button. The verification still completes server-side (the message is edited at line 191 and the record is inserted), but the user who clicked Finalize is shown a failure state, which is confusing for an honor-system verification flow and will generate support noise. Contrast with line 154 where the select-menu interaction IS correctly acknowledged via categoryInteraction.update().

**Location:** `src/commands/verify.ts:178-191`
**Category:** discord-api | **Confidence:** high | **Audit severity:** medium (adversarially confirmed)

**Suggested fix:** Capture the interaction and acknowledge it, e.g. `const finalizeInteraction = await uploadMessage.awaitMessageComponent({...}); await finalizeInteraction.deferUpdate();` (or .update({components: []})) before continuing.

**Evidence:** full-codebase multi-agent audit 2026-05-31, finding A0056. See audit/2026-05-31/full-codebase-audit.md.
