# #00191 -- review_action meta 'via' mislabels the @user-mention path as 'code' (reject)

**Type:** bug | **Priority:** Low

Both updateReviewActionMeta calls in executeReject use via: uidRaw ? "uid" : "code". The `user` (@mention) lookup path leaves uidRaw null, so a mention-based rejection is logged as via='code'. Inaccurate audit/analytics metadata for how the action was initiated.

**Location:** `src/commands/gate/reject.ts:213,222`
**Category:** data-integrity | **Confidence:** high | **Audit severity:** low (adversarially confirmed)

**Suggested fix:** Compute via from the actually-provided option: codeRaw ? 'code' : userOption ? 'mention' : 'uid', and use it in both the success and fetch-failure meta updates.

**Evidence:** full-codebase multi-agent audit 2026-05-31, finding A0041. See audit/2026-05-31/full-codebase-audit.md.
