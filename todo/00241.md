# #00241 -- Dead prefix clause for v1:avatar:confirm18 modals in the router guard

**Type:** refactor | **Priority:** Low

The modal dispatch guard `if (customId.startsWith("v1:modal:") || customId.startsWith("v1:avatar:confirm18:"))` includes the second clause solely for the avatar_confirm18 route. Since no modal with that customId is ever shown (see modalPatterns.ts finding) and there is no handler branch inside the block for it, the clause only serves to route such an ID into the block where it immediately hits the catch-all 'Unhandled modal' error card. The clause is effectively dead and misleading.

**Location:** `src/events/interactionCreate.ts:769`
**Category:** dead-code | **Confidence:** high | **Audit severity:** low (adversarially confirmed)

**Suggested fix:** Drop the `|| customId.startsWith("v1:avatar:confirm18:")` clause (coordinated with removing MODAL_18_RE), or implement the avatar_confirm18 handler if the feature is meant to ship.

**Evidence:** full-codebase multi-agent audit 2026-05-31, finding A0278. See audit/2026-05-31/full-codebase-audit.md.
