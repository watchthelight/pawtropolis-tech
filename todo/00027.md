# #00027 -- Add Discord webhook for cron workflow failures

**Type:** chore | **Priority:** Medium

.github/workflows/refresh-discord-badges.yml (daily 06:00 UTC) and update-badges.yml (every 6h) lack failure notifications. Cron failure leads to stale badges with no alert.

Action:
1. Add a post-job step with `if: failure()` that POSTs to a Discord webhook in both workflow files.
2. Store webhook URL as a GitHub Actions secret (e.g. CI_FAILURE_WEBHOOK).
3. Document in CREDENTIALS.md (gitignored) where the webhook points.
4. Test by introducing a fake failure on a branch and verifying the alert fires.

**Evidence:** audit/2026-05-19/deps-ops-findings.md (Finding 10)
