# #00293 -- Move the host to Node 24

**Type:** chore | **Priority:** High

Owner decision 5 (#00287): the whole host moves from Node 20 to Node 24 through apt, together with the 26.1.0 deploy.

Seen on the host on 2026-11-15: Node 20.20.2 comes from the NodeSource apt package and every PM2 app on the host runs on it, not only the bot and the dashboard. Node 20 passed its end of life in April 2026; Node 24 is supported to April 2028.

Before the switch, without touching a running app:

- List every app on the host with its native modules and its `engines` range.
- Install each app's dependencies under Node 24 in a temp copy and load its native modules.

At the switch: change the apt source to Node 24, reinstall each app's dependencies, restart, check each app. The way back is the Node 20 apt package and the same reinstall.

After it: the Node 20 test leg leaves CI, and better-sqlite3 no longer has to stay at 12.9.1 for its Node 20 binary.
