# #00109 -- Finalize button interaction is never acknowledged → user sees "This interaction failed"

**Type:** bug | **Priority:** Medium

The select-menu step correctly acknowledges its component interaction via categoryInteraction.update(...) (line 154). The Finalize step, however, only awaits the button via uploadMessage.awaitMessageComponent({...}) (lines 179-183) and discards the resulting ButtonInteraction without ever calling .update(), .reply(), or .deferUpdate(). discord.js collectors/awaitMessageComponent do NOT auto-acknowledge. Discord requires a component interaction to be acknowledged within 3 seconds; otherwise the clicking user is shown "This interaction failed". So every successful verification finalization shows the user an error toast even though the backend proceeds to insert the record, grant the role, and DM them. This is confusing and looks broken to end users in the exact honor-system flow the feature is built around.

**Location:** `src/commands/verify.ts:178-191`
**Category:** discord-api-misuse | **Confidence:** high | **Audit severity:** medium (adversarially confirmed)

**Suggested fix:** Capture the interaction and acknowledge it, e.g. `const finalizeInteraction = await uploadMessage.awaitMessageComponent({...}); await finalizeInteraction.deferUpdate();` (or .update({ components: [] })), then proceed. Mirror the pattern already used for categoryInteraction.update() on line 154.

**Evidence:** full-codebase multi-agent audit 2026-05-31, finding A0066. See audit/2026-05-31/full-codebase-audit.md.
