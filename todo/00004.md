# #00004 -- Upgrade Vite in web/ to patch dev-server path traversal

**Type:** security | **Priority:** High

web/ uses vite 7.3.1 which has unpatched path-traversal CVEs (GHSA-4w7w-66w2-5vf9, GHSA-p9ff-h696-f583). Impact is local dev only, but exposes the source tree when the dev server binds to a non-localhost address.

Action:
1. Upgrade vite in web/package.json to latest 7.x or 8.x.
2. Test `npm run dev` for Svelte integration breaks.
3. Verify `npm run build` still succeeds.
4. Document in web/README.md that the dev server must bind to localhost (or restrict via --host 127.0.0.1).

**Evidence:** audit/2026-05-19/deps-ops-findings.md (Finding 8)
