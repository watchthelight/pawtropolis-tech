# #00002 -- Patch HIGH and CRITICAL npm vulnerabilities

**Type:** security | **Priority:** Critical

npm audit --production reports a CRITICAL protobufjs RCE plus HIGH-severity issues in fastify (content-type validation bypass + X-Forwarded spoofing), undici (HTTP smuggling and WebSocket overflows), lodash (code injection via _.template), minimatch (ReDoS), fast-uri (path traversal), and jws (HMAC signature bypass).

Action:
1. Run `npm audit fix` on root and `web/`.
2. Upgrade fastify to >= 5.8.5 (covers content-type + X-Forwarded).
3. Upgrade discord.js to latest 14.x (pulls non-vulnerable undici) or pin undici >= 6.24.0.
4. Upgrade lodash to >= 4.17.24.
5. Upgrade minimatch to >= 9.0.7.
6. Re-run `npm audit` and verify HIGH count is zero.
7. Run `npm run typecheck && npm run test && npm run build` to validate.
