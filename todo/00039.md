# #00039 -- Add SSH host validation to deploy.sh

**Type:** chore | **Priority:** Low

deploy.sh:20 has REMOTE_HOST="${REMOTE_HOST:-bash-ec2}". Default is a local SSH alias. Running from a machine without that alias fails with an unclear error.

Action:
1. Add early validation in deploy.sh:
   ```
   if ! ssh-keygen -F "$REMOTE_HOST" >/dev/null 2>&1; then
     echo "ERROR: SSH host '$REMOTE_HOST' not in known_hosts. Configure in ~/.ssh/config." >&2
     exit 1
   fi
   ```
2. Document in README the REMOTE_HOST env var and how to set it for non-default environments.
