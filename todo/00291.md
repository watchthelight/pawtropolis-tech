# #00291 -- /purge requires a staff role in the handler

**Type:** security | **Priority:** Medium

Owner decision 8 (#00287). `/purge` deletes up to 100 messages in a channel. Its gate today is Discord's Manage Messages default permission plus the admin password. The handler has no role check, so anyone a server admin allows in the Integrations settings and who knows the password can run it.

The handler gets the staff check the other moderation commands use, in addition to the password. `docs/PERMS-MATRIX.md` follows.
