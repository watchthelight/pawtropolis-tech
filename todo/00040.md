# #00040 -- Validate Litestream configuration in CI / pre-deploy

**Type:** chore | **Priority:** Low

Litestream R2 backup config lives in .env.example but CI does not check presence. A missing env var on prod silently disables replication.

Action:
1. Add a script that validates required Litestream env vars (LITESTREAM_*).
2. Wire the script into deploy.sh as a pre-deploy check.
3. Optionally add a CI step that fails the build if .env.example is missing a Litestream var that production needs.
4. Log a warning at startup if Litestream is configured but not running.
