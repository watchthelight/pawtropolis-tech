# #00019 -- Add /listopen rate limit

**Type:** security | **Priority:** Medium

src/commands/listopen.ts:92-150 is staff-only with LRU caching (1-minute TTL) but no checkCooldown guard. A compromised moderator account or accidental spam could hammer the db.

Action:
1. Add `checkCooldown("listopen", interaction.guildId, 60 * 1000)` at the start of execute() before fetching draft applications.
2. Add LISTOPEN_MS constant to src/lib/rateLimiter.ts.
3. Add a unit test verifying the cooldown is enforced.

**Evidence:** audit/2026-05-19/security-findings.md (Finding 1)
