# #00261 -- Tighten .gitignore; generated artifact directories are tracked

**Type:** chore | **Priority:** Medium

`.gitignore` covers the obvious cases (node_modules, dist, secrets, `*.db`, tarballs) but several directories of generated output are tracked anyway. The repository carries roughly 170 MB of regenerable artifacts, and `.git` is 324 MB.

**Location:** `.gitignore`

**What is tracked and how big:**

| Path | Tracked files | Size |
|---|---|---|
| `graphify-out/` | 355 | 159 MB |
| `design_handoff/` | 11 | 5.4 MB |
| `audit/` | 53 | 2.4 MB |
| `_charts_out/` | 20 | 1.7 MB |
| `charts/` | 11 | 1.1 MB |
| `docs-audit/` | 3 | 60 KB |
| `context/` | 3 | 56 KB |

`graphify-out/` alone is most of the weight. `.gitignore` already carries a one-line exception for a single oversized PNG inside it (`graphify-out/exports/graph-connectome-fa2-raw-24000.png`, excluded for breaking GitHub's 100 MB limit), which suggests the directory was never meant to be committed wholesale.

**Second issue, separate decision:** `CLAUDE.md` is listed in `.gitignore` and is not tracked (`git ls-files --error-unmatch CLAUDE.md` fails). It is the file that documents this project's conventions, so a fresh clone gets none of them. Either it is deliberately local-only, or the ignore rule is wrong. Worth deciding explicitly.

**Suggested fix:**

1. Add the generated directories to `.gitignore`, keeping any hand-written files they contain (`audit/` and `docs-audit/` hold written reports, not just output, so check before ignoring wholesale).
2. `git rm -r --cached` the ones that should stop being tracked, so they leave the working tree alone but drop out of future commits.
3. Decide the `CLAUDE.md` question.

**Note on repository size:** ignoring these does not shrink `.git`. The 159 MB stays in history until it is rewritten with `git filter-repo`, which rewrites every commit hash and requires a force-push. That is a separate decision and should not be bundled into this task.

**Evidence:** `git ls-files` per directory with `du -ch`; `du -sh .git` = 324 MB.
