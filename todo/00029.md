# #00029 -- Increase PM2 kill_timeout for graceful shutdown

**Type:** chore | **Priority:** Medium

ecosystem.config.cjs:12-13 has the bot at kill_timeout: 5000 (5s). pawtropolis-web uses the PM2 default. If the bot is mid-migration or mid-bulk-fetch when restart fires, SIGKILL after 5s risks data corruption.

Action:
1. Increase kill_timeout to 15000 (15s) for the bot process.
2. Set kill_timeout to 10000 for pawtropolis-web.
3. Add an inline comment explaining the drain reason.
4. Test pm2 restart under simulated load; verify it waits the full window before hard-kill.
