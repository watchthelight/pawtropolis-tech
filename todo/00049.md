# #00049 -- Stats Observatory: public no-JS stats page with isolated theme

**Type:** feat | **Priority:** High | **Status:** `WIP`

Epic. Build a public, pure-CSS and no-JS stats page on pawtropolis.tech with its own fixed theme, unlike the rest of the site. Backed by precomputed rollup tables so render is sub-millisecond and trivially cacheable. Refreshable and deployable in one command. Server-rendered SVG and CSS charts only, no client JS chart library.

Delivered across six phases, tracked as child todos:
- `todo/00050.md` Phase 0: discovery and metric selection (BMAD)
- `todo/00051.md` Phase 1: isolated theme design
- `todo/00052.md` Phase 2: rollup migration, refresh script, query module
- `todo/00053.md` Phase 3: page build (route, SSR, SVG charts, zero hydration)
- `todo/00054.md` Phase 4: performance verification (Lighthouse, zero JS proof)
- `todo/00055.md` Phase 5: code review, docs, ship

Hard gates: typecheck, tests, build (root) and check (web) must pass before any phase is called done. Must not regress existing /dashboard routes or the dynamic OKLCH identity theming.
