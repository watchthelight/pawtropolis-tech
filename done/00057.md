# #00057 -- Fix web svelte-check type errors

**Type:** bug | **Priority:** Medium

`npm --prefix web run check` reports 15 errors across 4 files (warnings excluded). Root `npm run typecheck` is the CI hard gate and is clean; web svelte-check is not yet a CI gate, but these are real defects, one of them a runtime regression.

- `lib/stores/theme.ts` + `lib/components/layout/ThemeControls.svelte`: ThemeControls imports and calls `resetToDiscordTheme()`, which a refactor (a71dc96) removed along with its `_discordAccentColor` / `_discordAvatarUrl` backing state. The reset-to-Discord button currently throws at runtime. Restore the captured-values mechanism and the function.
- `routes/dashboard/audit/scans/+page.svelte`: 11 `'session' is possibly null` errors; guard or narrow once.
- `routes/dashboard/art/+page.svelte`: `thumbnailUrl` missing from the job row shape vs `ArtJobItem`.
- `lib/components/review/AppDetail.svelte`: 2 async handlers assigned to a `Callback` typed as returning `void`.

Action:
1. Fix each without changing intended behavior or weakening assertions.
2. `npm --prefix web run check` reaches 0 errors; `npm --prefix web run build` stays green.

**Done 2026-05-31:** All 15 errors fixed; `npm --prefix web run check` now reports 0 errors (93 warnings remain, the documented soft backlog). Web build green.
- theme.ts: re-added `_discordAccentColor` / `_discordAvatarUrl` state, captured them in applyTheme, restored the `resetToDiscordTheme()` export (replays applyTheme). The reset-to-Discord button works again.
- audit/scans/+page.svelte: replaced `.filter(Boolean)` with a typed guard `(s): s is NonNullable<typeof s> => s != null` so `session` narrows non-null (cleared all 11).
- art/+page.svelte: added `thumbnailUrl: null` to the optimistic job object (a freshly assigned job has no thumbnail yet).
- AppDetail.svelte: wrapped the two `onComplete: () => goto(...)` GSAP callbacks in block bodies with `void goto(...)` so they satisfy the `Callback` (() => void) type.

**Evidence:** npm --prefix web run check 2026-05-31.
