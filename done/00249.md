# #00249 -- archiveMessageRowSync / archiveReactionRowsSync are dead; 'used by backfill' comment is false

**Type:** refactor | **Priority:** Low

Both functions are exported with the comment 'Direct synchronous insert used by backfill (bypasses buffer).' But the only importer of messageArchive is src/events/guildEvents.ts via 'import * as archive', and that namespace only ever accesses archive.archiveMessage, markMessageDeleted, recordReaction, removeReaction (verified by listing archive.* member access). Neither *RowSync function is referenced anywhere in src/scripts/tests/web (verified by name grep, no dynamic/string refs). The backfill command (commands/backfill.ts) contains no 'archive' reference at all. So these are dead exports with a misleading comment that implies a live consumer that does not exist.

**Location:** `src/features/messageArchive.ts:195, 201`
**Category:** Unused export (stale comment) | **Confidence:** high | **Audit severity:** low (adversarially confirmed)

**Suggested fix:** Remove archiveMessageRowSync and archiveReactionRowsSync (and the ArchiveRow/ReactionRow plumbing if it becomes unused), or actually wire them into the backfill path the comment references. Confirm backfill genuinely does not need synchronous inserts first.
