# #00279 -- Owner-only /investigate-artist for 2D artist verification tickets

**Type:** feat | **Priority:** High

New slash command for v26. Run inside a 2D artist verification ticket, it gathers the ticket history and every image the applicant posted, runs reverse image search and art-site lookups, sends the evidence to the Claude API, and returns a private, advisory assessment mapped to the server's verification workflow.

Design, workflow sources, service choices and limits: `MODERNIZATION_PLAN.md` section 5.

- Owner only, enforced in the handler. Ephemeral. Nothing is posted in the ticket or logged publicly.
- Works on first-party tickets and on Ticket Tool channels (production still uses Ticket Tool).
- Provenance: Fluffle (no key), e621 and SauceNAO (skipped and named as skipped without keys).
- Cost tracking per run, monthly total, configurable monthly cap.
- Advisory only: never approves, denies, assigns roles or messages the applicant.

**Resolution (2026-11-14, 26.0.0):** shipped on `release/v26`. Migration 084, `src/features/artistInvestigation/`, `src/commands/investigate-artist.ts`, tests with every external API mocked, and the handbook, permission matrix and env docs. Two dry runs against a real four-image ticket took 74 and 78 seconds and cost 0.17 and 0.18 USD, and led to six fixes. The command has not run as a real Discord interaction yet, because there is no test guild. SauceNAO and e621 need keys before they return anything (#00287).
