**Type:** chore | **Priority:** Medium | **Status:** `COMPLETE 2026-05-19`

deploy.sh:47 sets DEPLOY_LOCK_DIR="/tmp/pawtropolis-deploy.lock". /tmp is world-writable on Unix; any user on the EC2 box could rm -rf the lock and hijack a concurrent deploy.

**Resolution (2026-05-19):** Default moved to /home/ubuntu/pawtropolis-deploy.lock in commit fa4d05f. Home dir is owned by the deploy user (ubuntu); non-root users on the box cannot remove the lock. mkdir/rm logic already uses the env var, no code changes needed. Help text updated to reflect new default. Contention test deferred until next deploy.
