# #00073 -- Intended-ephemeral claim feedback becomes a public edit of the review card (flags dropped after deferUpdate)

**Type:** bug | **Priority:** High

handleClaimToggle is always entered AFTER the parent handleReviewButton called interaction.deferUpdate() (src/features/review/handlers/buttons.ts:177-181). deferUpdate() sets interaction.deferred = true (discord.js InteractionResponses.deferUpdate -> this.deferred = true), and for a component interaction the response '@original' is the message the button is attached to: the public review card. Every feedback call here uses replyOrEdit(interaction, { content, flags: MessageFlags.Ephemeral }). But replyOrEdit (src/lib/cmdWrap.ts:503-506) takes the deferred branch and explicitly strips flags (`const { flags, ...editPayload } = withFlags; interaction.editReply(editPayload)`), which PATCHes '@original'. Net effect: messages meant to be private to the clicking moderator -- 'This application is already claimed by another moderator.', 'Cannot claim: application is already X.', 'An unexpected error occurred.', and especially 'This user has been permanently rejected from <server> and cannot reapply.' (lines 91-93) -- are written publicly onto the shared review card, overwriting its content line and exposing internal moderation state to everyone who can see the channel. The success path (lines 146-150) similarly edits the card content rather than sending the intended per-mod confirmation.

**Location:** `src/features/review/handlers/claimHandlers.ts:62-67, 74-79, 84-102, 146-150`
**Category:** correctness | **Confidence:** high | **Audit severity:** high (adversarially confirmed)

**Suggested fix:** After an upstream deferUpdate(), do not use replyOrEdit for per-moderator feedback. Use interaction.followUp({ content, flags: MessageFlags.Ephemeral }) directly (followUp preserves flags and posts a separate ephemeral message), or have replyOrEdit honor ephemeral by routing to followUp when the interaction was deferred via deferUpdate rather than calling editReply. At minimum, stop stripping flags for genuinely ephemeral content.

**Evidence:** full-codebase multi-agent audit 2026-05-31, finding A0118. See audit/2026-05-31/full-codebase-audit.md.
