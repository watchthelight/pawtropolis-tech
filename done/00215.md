# #00215 -- Unreachable null branch in lensUrl ternary

**Type:** refactor | **Priority:** Low

avatarUrl is set from user.displayAvatarURL({ size: 128 }) (line 364), which always returns a non-empty CDN URL string, never null/empty. The ternary at lines 369-371 (`avatarUrl ? ... : null`) therefore always takes the truthy branch; the `: null` and the later `if (lensUrl)` guard (line 389) are effectively dead. No runtime impact, but misleading defensive code.

**Location:** `src/features/modmail/threadOpen.ts:369-371`
**Category:** dead-code | **Confidence:** high | **Audit severity:** low (adversarially confirmed)

**Suggested fix:** Drop the ternary and unconditionally build lensUrl from the encoded avatarUrl, or remove the dead null branch/guard.
