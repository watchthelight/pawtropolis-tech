# #00059 -- Changelog web page and full changelog refresh

**Type:** feat | **Priority:** Medium

`pawtropolis.tech/CHANGELOG.md` returned 404: the repo `CHANGELOG.md` lives at the
root, outside the web app's served paths. The changelog was also stale (last entry
6.0.0, 2026-05-15) with nothing for the work since.

**Done 2026-05-31:**
- Brought `CHANGELOG.md` fully current: populated the `[Unreleased]` section with
  every change since 6.0.0 (Stats Observatory, TypeScript strict mode, vitest 4
  upgrade, the index/dashboardApi/audit/serverAuditDocs/gate refactors, the May
  security patches, the test-coverage and CI/deploy hardening, and the error-card
  ping rate limit), grouped Added/Changed/Fixed/Security/Internal with todo IDs.
- Added a themed `/changelog` page (`web/src/routes/changelog/+page.{server.ts,svelte}`).
  It inlines the repo `CHANGELOG.md` at build time via Vite `?raw` (the handbook's
  pattern, so no runtime filesystem access on EC2), renders it with `marked`, and
  adds GitHub-style heading ids so the in-document version nav resolves. Styled with
  the site theme tokens. SSR (not prerendered) because the changelog's own nav links
  to a couple of historical version anchors that have no heading section, which the
  prerender anchor validator rejects.
- Added `web/src/routes/CHANGELOG.md/+server.ts`: 308-redirects the old `/CHANGELOG.md`
  URL to `/changelog`.

Verified: web build green; booted the adapter-node server and confirmed `/changelog`
returns 200 with the rendered current changelog and `/CHANGELOG.md` 308-redirects to it.
