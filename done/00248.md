# #00248 -- review/index.ts is a fully unused duplicate barrel; the live back-compat barrel is review.ts

**Type:** refactor | **Priority:** Low

There are two barrels for the review module: src/features/review.ts (128 lines) and src/features/review/index.ts (113 lines). Both headers claim to provide 'backwards compatibility with imports from ./features/review.js'. Only review.ts is actually imported (e.g. gateMain.ts:30 renderWelcomeTemplate, web/routes/review.ts:23 ensureReviewMessage). review/index.ts would only be reached via an import from '...features/review' with no further path segment, and grep for that exact pattern (from '<...>features/review') returns ZERO matches across src/web/scripts/tests. It contains only re-exports (no side effects), so it is pure dead source. Its re-exports of DEFAULT_WELCOME_TEMPLATE and buildWelcomeNotice are doubly dead -- those symbols are also re-exported by review.ts and used only internally inside review/welcome.ts.

**Location:** `src/features/review/index.ts:1-113`
**Category:** Dead duplicate barrel / unused export | **Confidence:** high | **Audit severity:** low (adversarially confirmed)

**Suggested fix:** Delete src/features/review/index.ts. Keep src/features/review.ts (the one consumers actually import). If a directory-style barrel is desired long-term, consolidate to one and update review.ts importers, but do not keep both.
