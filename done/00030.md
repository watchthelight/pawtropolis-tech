# #00030 -- Add CI smoke test for built artifact

**Type:** chore | **Priority:** Medium | **Status:** `COMPLETE 2026-05-19`

.github/workflows/ci.yml runs unit tests and build but does not verify the built artifact starts. A broken import would pass CI and fail at runtime.

**Resolution (2026-05-19):** Added `node --check dist/index.js` smoke step to the build job in ci.yml (commit 5fe2eb0). Validates syntax + import resolution without executing - no Discord creds or DB needed. Doesn't catch all runtime issues (e.g. db.prepare at module load) but blocks the most common breakage class (broken imports, syntax errors in build output). A fuller boot-check would require a `--health-check` flag in src/index.ts; deferred until needed.

Action:
1. Add a smoke step to ci.yml: `node dist/index.js --health-check` (the bot supports a quick health-check exit code).
2. Confirm src/index.ts supports the --health-check arg, or add it.
3. Fail the CI job if the smoke exits non-zero.
4. Document the dependency in docs/operations/ci-policy.md.
