# #00287 -- Owner decisions from the v26 audit

**Type:** question | **Priority:** High

Listed with options and a recommendation in `MODERNIZATION_PLAN.md` section 7: reverse image search accounts (SauceNAO, e621), differences between the handbook and the public artist requirements, whether `/investigate-artist` should read the private staff thread, the dashboard API loopback bind, moving the host from Node 20 to Node 24, gating the dashboard deploy that a push to main starts on CI, rotating the GitHub bot token, `/purge` policy, the ticket system cutover, features and files that look dead, unused indexes, one open ticket per user per type, untracking `.playwright-mcp/`, a test server, the seven dead cron jobs on the host, and the avatar scans that fail on every join because billing is off for Google Vision.

Two of them have the change ready on a branch that sits one commit on top of the release:

- `hold/v26-one-open-ticket-per-type`: the open button answers with a link to the ticket the user already has instead of opening another. Merge it or delete it.
- `hold/v26-untrack-playwright-mcp`: removes 60 tracked browser session files and ignores the directory. Merging deletes them from any checkout that has them, so copy the directory first if you want the files.

**Resolution (2026-11-15):** the owner went through all sixteen. The wording of each decision is in `MODERNIZATION_PLAN.md`, section 7. In short, by item number:

1. Image lookups: both accounts, and Google's web detection as a third lookup, with the keys settable from Discord (#00289, #00290).
2. Evidence rules: the handbook wins, all three six-month rules count, and base-made work counts when the base creator is credited (#00292).
3. Staff thread: the command stays out of it.
4. Dashboard API bind: stays on loopback. Nothing to decide.
5. Node: the whole host moves to Node 24 through apt, with the 26.1.0 deploy (#00293).
6. Dashboard deploy: it waits for CI now.
7. GitHub bot token: closed by the owner.
8. `/purge`: requires a staff role in the handler (#00291).
9. Ticket cutover: on hold, and the guide says so at its top.
10. Dead-looking features and files: every command stays. `scripts/deploy-commands.ts`, `TODO.md` and `CLAUDE_CODE_PROMPT.md` were removed; #00288 keeps the lines of `TODO.md` that were still open.
11. Indexes: the two big ones on `messages_archive` that no query was found for get checked for the next release (#00294).
12. One open ticket per user per type: merged.
13. `.playwright-mcp/`: untracked, after a copy was made outside the repo.
14. Test server: none.
15. Research cron jobs: the pipeline comes back, scope and plan first (#00295).
16. Avatar scan: stays, and its key becomes settable from Discord (#00289).

Release 26.1.0 (#00296) carries the work that needs a bot deploy.
