# #00190 -- review_action meta 'via' mislabels the @user-mention path as 'code'

**Type:** bug | **Priority:** Low

updateReviewActionMeta is called with via: uidRaw ? "uid" : "code". There are three identifier inputs: app (short code), user (@mention), and uid. When a moderator approves via the `user` mention option, uidRaw is null so via is recorded as "code", even though no short code was used. This corrupts the analytics the comment at lines 329-330 explicitly says this field exists for ('track whether mods prefer short codes or user IDs'). Same pattern in reject.ts.

**Location:** `src/commands/gate/accept.ts:336`
**Category:** data-integrity | **Confidence:** high | **Audit severity:** low (adversarially confirmed)

**Suggested fix:** Derive via from which option was actually provided, e.g. const via = codeRaw ? 'code' : userOption ? 'mention' : 'uid'; and pass that. Apply identically in reject.ts.

**Evidence:** full-codebase multi-agent audit 2026-05-31, finding A0040. See audit/2026-05-31/full-codebase-audit.md.
