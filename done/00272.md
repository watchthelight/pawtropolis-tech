# #00272 -- Documentation truth: parity tests for commands, env, permissions and config; archive stale generated docs

**Type:** chore | **Priority:** High

The docs describe a bot that no longer exists in places: `docs/index.md`, `project-overview.md`, `architecture.md`, `source-tree-analysis.md`, `api-contracts.md`, `data-models.md`, `SLASH-COMMANDS.md` and `project-scan-report.json` are machine-generated snapshots from March to June that still say version 5.1.1 and 37 slash commands (53 are registered). 70 env names are read in code but missing from `.env.example`, 8 documented keys are never read, and the dashboard config editor cannot edit 17 columns the bot accepts.

**Plan**

- `perms-matrix.test.ts`: role ids in `docs/PERMS-MATRIX.md` match `src/lib/roles.ts`; per-command tiers match the code.
- `config-editor.test.ts`: the bot's `ALLOWED_CONFIG_COLUMNS` equals the dashboard's editable field set (feeds #00273).
