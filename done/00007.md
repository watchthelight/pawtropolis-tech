# #00007 -- Refactor src/index.ts (2705 lines) into event modules

**Type:** refactor | **Priority:** High

src/index.ts is 2,705 lines and orchestrates 30+ Discord event handlers inline (guildCreate, messageCreate x3, threadDelete, voiceStateUpdate, etc.), interaction routing, startup/shutdown, and error wiring. Single file is the universal touchpoint for any event change.

Action:
1. Create src/events/ directory.
2. Extract each event handler to its own file: src/events/guildCreate.ts, src/events/messageCreate.ts, src/events/threadDelete.ts, etc.
3. Move the interaction router to src/features/interactionRouter.ts.
4. index.ts becomes the registration site only: import handlers, attach to client, start lifecycle. Target under 300 lines.
5. Verify each event still fires correctly. Test in dev with a real Discord guild.

**Evidence:** audit/2026-05-19/code-quality-findings.md (Finding 1)
