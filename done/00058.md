# #00058 -- Rate limit the error-card Ping developer button

**Type:** bug | **Priority:** High

The "Ping developer" button on error cards (`ec:ping:<traceId>`) had no cooldown. A single error card was hammered, pinging the bot dev 10+ times in under a minute for the same trace (observed in #development, trace `JhV1n4UvmDY`). Public-mention spam.

Action:
1. Add `COOLDOWNS.ERRORCARD_PING_MS` (10 minutes) and gate `handlePing` in `src/handlers/errorCardButtons.ts` with `checkCooldown("errorcard_ping", traceId, ...)`.
2. Scope by trace ID so one error pings the dev once per window regardless of who clicks or how often.
3. Blocked clicks reply ephemerally (no new public ping).

**Done 2026-05-31:** Added the constant and the per-trace cooldown check. Blocked clicks now get an ephemeral "already pinged about trace X, try again in Nm" reply instead of emitting another public ping. typecheck 0, 5457 tests green.

**Evidence:** #development screenshot 2026-05-31 (same trace pinged 10+ times).
