# #00027 -- Add Discord webhook for cron workflow failures

**Type:** chore | **Priority:** Medium | **Status:** `COMPLETE 2026-05-19`

.github/workflows/refresh-discord-badges.yml (daily 06:00 UTC) and update-badges.yml (every 6h) lack failure notifications. Cron failure leads to stale badges with no alert.

**Resolution (2026-05-19):** Added `Notify Discord on failure` step with `if: failure()` to both workflows in commit ed9a7ec. Reads `secrets.DISCORD_CI_WEBHOOK` and gracefully no-ops if unset (so the workflow doesn't fail just because the secret is missing). Webhook secret needs to be created at https://github.com/watchthelight/pawtropolis-tech/settings/secrets/actions and pointed at a Discord channel webhook URL. Live verification deferred until secret is configured.
