# #00171 -- Entire /analytics command module is dead (never registered or imported)

**Type:** refactor | **Priority:** Low

command.ts exports executeAnalyticsCommand, executeAnalyticsExportCommand, and parseWindow - full slash-command handlers for an /analytics command. But "analytics" is NOT in src/commands/runtimeManifest.ts SLASH_COMMAND_NAMES, is not registered in src/index.ts, and the module is imported by nothing in src/ (only tests/features/analytics/command.test.ts references it). The functionality was reimplemented under src/commands/stats/ (the consolidated /stats command). A startup drift guard in index.ts (lines 274-294) enforces that registered handlers match the manifest, so this module can never be reached at runtime. ~481 lines of dead handler code plus a test suite that only exercises dead code.

**Location:** `src/features/analytics/command.ts:1-481`
**Category:** dead-code | **Confidence:** high | **Audit severity:** low (adversarially confirmed)

**Suggested fix:** Delete src/features/analytics/command.ts and tests/features/analytics/command.test.ts. Confirm /stats fully covers the prior /analytics summary + export behavior before removal.

**Evidence:** full-codebase multi-agent audit 2026-05-31, finding A0273. See audit/2026-05-31/full-codebase-audit.md.
