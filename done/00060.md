# #00060 -- Re-skin /observatory as a classic Windows 95/98 desktop

**Type:** feat | **Priority:** Medium

Owner asked to completely change the public `/observatory` page to a classic
Windows 95/98 desktop look (chosen over a flat Windows 10 Metro look), keeping it
pure performance: raw HTML/CSS, zero client JS, no webfonts, no images.

**Done 2026-05-31:** Reskinned in two files; all 11 chart components untouched
(they recolor from the `--obs-*` tokens).
- `web/src/lib/styles/observatory.css`: remapped every token to a Win95 palette
  (teal `#008080` desktop, silver `#c0c0c0` control face, white sunken client
  wells, VGA 16-color chart series, navy title bars). Replaced the night-sky
  gradient + animated CSS starfield with a flat teal desktop (a net paint win) and
  the rounded/glowing surfaces with the authentic 4-inset 3D-bevel recipe
  (`--obs-raised` / `--obs-sunken`). Square corners, Tahoma/MS Sans, dotted focus
  rectangles, classic blue underlined links. Chart cards (`:has(> .obs-chart-title)`)
  render as sunken white wells with a navy title-bar strip; KPI cards stay raised
  silver tiles. Overrode the few baked-in night-sky decorations on `.hero-stat`.
- `web/src/routes/observatory/+page.svelte`: wrapped the content in a window body
  and added a window title bar (`_ □ X`, aria-hidden, no JS); restyled the masthead,
  KPI band, and turned the provenance footer into a sunken status bar; theme-color
  meta -> `#008080`.

Verified: web `check` 0 errors, build green, local boot served 200 with **zero
`<script>` tags** (zero-JS held). Pushed to main (d279a8f) and deployed
`./deploy.sh --web`; live `https://pawtropolis.tech/observatory` returns 200, 125 KB,
0 scripts, data populated. Screenshot confirmed the Win95 desktop renders correctly
with full chart legibility on the white wells.

**Evidence:** owner request 2026-05-31 ("old windows 10 themed" -> selected classic 95/98 gray).
