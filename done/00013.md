# #00013 -- Refactor src/features/flagsStore.ts for testability

**Type:** bug | **Priority:** Medium | **Status:** `COMPLETE 2026-05-19`

**Resolution (2026-05-19):** Note: file lives at src/store/flagsStore.ts (not src/features/). Refactored to lazy-prepare pattern in commit ff9bdcd:
- Added `lazyStmt(sql)` memoized factory keyed by SQL string.
- Each `const xStmt = db.prepare(...)` -> `function xStmt(): PreparedStmt { return lazyStmt(...) }`.
- All call sites updated from `xStmt.method` to `xStmt().method`.
- Typed via `Statement<unknown[], unknown>` from better-sqlite3.

Module no longer touches db at import time. Mocking now works.
